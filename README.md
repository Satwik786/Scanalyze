# Scanalyze

**Scanalyze** is a smart, health-focused food scanner and rating system that helps consumers uncover the truth behind packaged foods.  
It allows users to scan barcodes, search products, and explore ingredient breakdowns with clear insights into nutrition, additives, and health ratings.


## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/scanalyze.git
   cd scanalyze
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   node backend/server.js
   ```
4. Open in browser:
   ```
   http://localhost:3000
   ```
